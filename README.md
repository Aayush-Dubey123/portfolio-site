## Not Your Normal Portfolio

This is not designed as a conventional static portfolio website.

The experience is built around the idea of a **cinematic digital journey** where the interface, motion, content, and visual environment work together instead of presenting everything as a collection of separate cards and sections.

The portfolio uses a continuous visual experience controlled by the user's interaction, while the actual portfolio information remains clear, accessible, and usable.

The goal is simple:

> **Make exploring a portfolio feel like experiencing a story rather than reading a resume on a webpage.**

## Technology

Built with a modern frontend stack including:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion
- Responsive UI
- Component-based architecture

The project also uses a centralized data structure so portfolio information can be maintained independently from the UI.

---

## Development Philosophy

The project focuses on:

- cinematic interaction
- smooth motion
- performance
- responsive design
- clear information hierarchy
- reusable components
- maintainable architecture
- meaningful interaction rather than unnecessary decoration

The visual experience is intentionally expressive, but the portfolio content remains the primary purpose of the site.
